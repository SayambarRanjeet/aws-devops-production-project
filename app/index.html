Welcome to DevOps Production Project

This website is deployed automatically using a complete DevOps CI/CD pipeline.

Technologies used in this project:

  • GitHub – Source Code Management
  • Jenkins – CI/CD Automation
  • Docker – Containerization
  • AWS EC2 – Application Hosting
  • Terraform – Infrastructure as Code

This project demonstrates how code changes pushed to GitHub automatically trigger Jenkins, build a Docker image, and deploy the application to an AWS EC2 server.

Automated CI/CD Pipeline using Jenkins

Every time new code is pushed to GitHub, the Jenkins pipeline automatically builds and deploys the latest version of the application.
